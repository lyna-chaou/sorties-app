Sorties App est un projet personnel que j'ai développé en Java avec Spring Boot durant ma deuxième année de BUT Informatique
afin de pratiquer le développement web back-end et l'architecture MVC. L'application permet de rechercher des idées de sorties comme des cinémas,
des centres commerciaux, des bowlings ou des musées en saisissant simplement le nom d'une ville. 
Pour éviter d'utiliser des API externes payantes tout en gardant des résultats réalistes, j'ai intégré une base de vrais lieux 
pour certaines villes comme Paris, Lyon ou Argenteuil, ainsi qu'un système de génération automatique pour toutes les autres communes.
Le projet utilise Thymeleaf et HTML/CSS pour l'affichage, et se lance directement en exécutant la classe SortiesAppApplication a
vant d'ouvrir l'adresse http://localhost:8080 dans un navigateur.
